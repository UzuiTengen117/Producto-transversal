JavaScript en el navegador

JavaScript permite reaccionar a clics y actualizar la página sin recargarla. La demo siguiente usa querySelector, variables, bucles for y condiciones para armar contenido y responder a eventos.

    Qué hace el código

    Variables guardan el nivel elegido, el bloque de temas encontrado y contadores. Los bucles recorren el catálogo y cada tema para crear nodos <li>. Las condiciones eligen el mensaje del resumen, alternan clases visuales y calculan el texto de progreso al marcar filas.

    Elementos del DOM tocados

    • #jsHeadline, #jsTopicBadge, #jsProgressHint
    • #jsConceptList (lista generada) y #jsSummary (resumen)

    Por qué importa

    Manipular el DOM con JavaScript es la base de formularios dinámicos, paneles y aplicaciones de una sola página. Separar datos (arreglos de temas) de la vista facilita ampliar niveles o añadir interactividad sin recargar.

    • UX: respuesta inmediata al usuario.
    • Accesibilidad: textos con aria-live en los cambios importantes.
    • Mantenimiento: un solo lugar (catalog) define los temas por nivel.
