Etiquetas HTML5 Esenciales

HTML5 introdujo etiquetas semánticas que no solo estructuran el contenido visualmente, sino que también proporcionan significado para buscadores y lectores de pantalla.

📄

<article>

Uso Básico: Define contenido independiente y autónomo. Un artículo debería tener sentido por sí mismo, y debería ser posible distribuirlo independientemente del resto del sitio.

<article>
  <h2>Título del post</h2>
  <p>Contenido...</p>
</article>
🧭

<nav>

Uso Básico: Representa una sección de una página cuyo propósito es proporcionar enlaces de navegación, ya sea dentro del documento actual o a otros documentos.

<nav>
  <ul>
    <li><a href="#">Inicio</a></li>
  </ul>
</nav>
🖼️

<figure> & <figcaption>

Uso Básico: Se utiliza para encapsular contenido multimedia (como imágenes, diagramas, código) junto con un título opcional que lo describe.

<figure>
  <img src="img.jpg" alt="...">
  <figcaption>Descripción</figcaption>
</figure>
📅

<time>

Uso Básico: Representa una fecha y/o hora específica. Útil para que los motores de búsqueda interpreten las fechas de publicación correctamente.

<p>Publicado el <br>
<time datetime="2023-10-25">
25 de Octubre</time></p>
📊

<progress> & <meter>

Uso Básico: 'progress' muestra el progreso de una tarea, mientras que 'meter' representa un valor escalar dentro de un rango conocido (como el uso de disco).

<progress value="70" max="100"></progress>
<meter value="2" min="0" max="10"></meter>

Elementos de Control Interactivos

Explora cómo funcionan diferentes tipos de inputs y controles HTML en tiempo real. Interactúa con ellos para ver su comportamiento.

1. Entrada de Texto

Un campo de texto estándar (type="text") para datos alfanuméricos cortos. Incluye un placeholder.

Valor actual: {{ textValue || '(vacío)' }}

2. Control de Rango (Slider)

Selector numérico visual (type="range") ideal para ajustar volumen, brillo o valores aproximados.

Nivel seleccionado: {{ rangeValue }}%

3. Selector de Color

Permite elegir un color mediante la interfaz del sistema (type="color"). Útil para personalización de temas.

Color hexadecimal: {{ colorValue }}

4. Selector de Fecha

Abre un calendario nativo del navegador (type="date") asegurando un formato de fecha consistente.

Fecha seleccionada: {{ dateValue || 'Ninguna' }}

5. Casilla de Verificación

Un type="checkbox" estilizado como un interruptor. Permite activar o desactivar opciones binarias.

Estado del sistema: {{ switchValue ? 'ACTIVADO' : 'DESACTIVADO' }}
