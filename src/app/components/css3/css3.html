Propiedades CSS3 Fundamentales

Dominar estas propiedades te permite construir interfaces limpias, jerárquicas y adaptables a diferentes dispositivos sin depender de librerías externas.

🎨

Color, Fondos y Gradientes

Uso básico: CSS3 permite definir colores sólidos, transparencias y degradados para crear profundidad visual y reforzar la identidad de una interfaz.

.banner {
  background: linear-gradient(135deg, #8b5cf6, #3b82f6);
  color: #fff;
}
📐

Flexbox para Distribución

Uso básico: Facilita alinear elementos horizontal y verticalmente, repartir espacios y construir componentes ordenados con poco código.

.card-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
🧱

Grid para Layout Complejo

Uso básico: CSS Grid organiza contenido en filas y columnas para crear diseños robustos y responsivos, ideales para dashboards y portales.

.dashboard {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
✨

Transiciones y Estados

Uso básico: Las transiciones suavizan cambios visuales cuando el usuario interactúa con botones, enlaces o tarjetas.

.btn {
  transition: transform 0.3s ease;
}
.btn:hover {
  transform: translateY(-3px);
}
📱

Media Queries

Uso básico: Adaptan tipografías, espaciados y columnas para que la interfaz sea usable en escritorio, tablet y móvil.

@media (max-width: 768px) {
  .grid { grid-template-columns: 1fr; }
}

Ejemplos de Reglas CSS3 Aplicadas a HTML

En esta sección puedes ver cómo una regla CSS3 transforma directamente un elemento HTML. Cada tarjeta incluye el código y su resultado visual.

1. Botón con transición

Regla CSS aplicada a un <button> para generar un efecto suave al pasar el cursor.

.demo-button {
  background: #8b5cf6;
  transition: transform .3s ease;
}
.demo-button:hover {
  transform: translateY(-4px);
}
HTML: <button class="demo-button">...</button>

2. Tarjeta con sombra y borde redondeado

Regla CSS para dar profundidad visual a un <div> con box-shadow y border-radius.

.demo-box {
  border-radius: 14px;
  box-shadow: 0 10px 25px rgba(0,0,0,.35);
  background: rgba(15,23,42,.7);
}
Soy un DIV estilizado con CSS3
HTML: <div class="demo-box">...</div>

3. Texto con gradiente

Regla CSS para aplicar un gradiente a un encabezado <h4> usando background-clip: text.

.demo-gradient-text {
  background: linear-gradient(90deg, #22d3ee, #a78bfa);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
}

CSS3 hace destacar el contenido

HTML: <h4 class="demo-gradient-text">...</h4>

4. Animación CSS3 con keyframes

Ejemplo de animación continua aplicada a un <div> para simular un “loader”.

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
.demo-loader { animation: spin 1.2s linear infinite; }
HTML: <div class="demo-loader"></div>
